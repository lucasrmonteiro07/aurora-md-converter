# ⚡ Início Rápido

## 30 segundos para começar

### 1. Configure a chave API
```bash
# Edite .env com sua chave GROQ API
VITE_GROQ_API_KEY=sua_chave_aqui
```

### 2. Inicie o servidor
```bash
npm install  # (primeira vez apenas)
npm run dev
```

### 3. Abra no navegador
```
http://localhost:5173
```

## 2 minutos para fazer seu primeiro upload

1. **Selecione um arquivo**: TXT, DOCX, XLSX ou CSV
2. **Clique em converter**: Aguarde a IA processar
3. **Baixe ou copie**: Seu Markdown está pronto!

## Deploy em 5 cliques (Vercel)

1. Push para GitHub
2. Acesse https://vercel.com
3. Import do GitHub
4. Defina `VITE_GROQ_API_KEY`
5. Deploy automático! 🚀
